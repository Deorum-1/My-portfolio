## The goal

Make it easy to find movies by title and explore popular picks.

## What I built

The app searches The Movie Database and displays popular titles and search results. It also connects to Appwrite to track trending searches.

## Tools and decisions

The frontend uses React and Vite, with Appwrite for search tracking and the TMDB API for movie information.
