## The goal

Make property listings easy to browse and help visitors narrow down options through clear search and filtering controls.

## What I built

I built a responsive real estate interface with structured listing information, category filters and layouts that adapt across screen sizes.

## Tools and decisions

React and JavaScript manage the listing experience, while Tailwind CSS provides the responsive visual system.
