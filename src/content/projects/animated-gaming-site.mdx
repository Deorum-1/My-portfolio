## The goal

Create an energetic gaming website that feels interactive while keeping the content clear and easy to navigate.

## What I built

I built a responsive React experience with motion-rich sections, animated transitions and an interface designed around the game theme.

## Tools and decisions

React and JavaScript provide the component structure, while GSAP handles focused animation sequences and scroll-based movement.
