## The goal

Present development projects and experience in one place with interactive ways to explore featured work.

## What I built

The portfolio includes project showcases, an interactive device-frame previewer, a multi-palette theme switcher and a resume viewer.

## Tools and decisions

The site uses React, Vite, Tailwind CSS and GSAP. It also includes interactive UI features such as a browser-based audio toggle and theme persistence.
